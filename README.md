# Context CLI 🧠

> **Turn your entire codebase into a single, AI-ready text file in seconds.**

A lightweight tool that scans your directory, ignores junk files (like `node_modules`, `.git`, images), generates a visual file tree, and formats everything into a clear context prompt for LLMs (ChatGPT, Claude, DeepSeek, etc.).

It works via a simple `curl` command—no installation required.

## 🚀 Quick Start

Run this command in the root of your project on any VPS, Mac, or Linux machine:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/milibots/context-cli/main/context.sh)"
